### **Overlapping Patch Inference (Stride Modification)**

The most direct and physically grounded method to extract higher spatial frequency from a frozen Vision Transformer involves altering the stride of the initial patch embedding convolution. In the DINOv2 architecture codebase, the PatchEmbed mechanism is instantiated as a standard torch.nn.Conv2d layer initialized with kernel\_size=(14, 14\) and stride=(14, 14).5 Because the stride equals the kernel size, the resulting patches are perfectly contiguous and non-overlapping.

This inherently provides true sub\-![][image6]\-pixel spatial predictions because the physical distance between the centers of adjacent tokens is physically reduced to ![][image65] pixels.14 The feature vectors now encode shifting, overlapping perspectives of the underlying geometry.  
However, implementing stride modification introduces severe complications regarding the absolute positional embeddings. DINOv2 is pre-trained with a fixed positional embedding tensor corresponding to a specific sequence length. The architecture includes a dynamic mechanism, interpolate\_pos\_encoding, to handle varying sequence lengths. A forensic analysis of the DINOv2 source code reveals a critical limitation when hacking the stride parameter.16 The interpolate\_pos\_encoding function explicitly hardcodes the original patch size to determine the interpolation scaling factors: w0 \= w // self.patch\_size h0 \= h // self.patch\_size

### **Suppression of Background Artifacts via Register Tokens**

A secondary, yet highly critical, consideration for spatial fidelity in remote sensing is the suppression of high-norm spatial artifacts. Extensive forensic analyses of the original DINOv2 architecture revealed a systemic flaw in how Vision Transformers manage internal representations. Lacking a dedicated spatial memory, ViTs tend to arbitrarily repurpose low-information background patches—such as uniform bodies of water, barren earth, or featureless concrete in satellite imagery—to store global, image-wide contextual features.21  
During inference, these repurposed patches manifest as high-norm tokens, creating severe spatial artifacts that brutally corrupt dense prediction tasks like segmentation. An otherwise uniform area will suddenly present highly anomalous feature similarities, destroying the continuity of the segmentation mask.22  
To permanently resolve this architectural defect without incurring computational penalties, Meta introduced the DINOv2-with-registers (dinov2\_vitb14\_reg) variants.2 By explicitly appending four empty, learnable "register" tokens to the input sequence alongside the standard \`\` token, the model is provided with a dedicated, non-spatial memory workspace for global information processing.6 The background spatial patches are immediately relieved of this computational burden, resulting in extraordinarily smooth, artifact-free local feature maps that adhere strictly to semantic boundaries.22  
Migrating the frozen backbone from dinov2\_vitb14 to dinov2\_vitb14\_reg requires zero additional VRAM for patch tokens—the four extra tokens have negligible impact on sequence length and multi-head attention matrices.24 For remote sensing tasks where boundary delineation and area uniformity are paramount, swapping to the register variant is an absolute architectural imperative that provides an immediate, cost-free upgrade to spatial fidelity.

### **Task-Agnostic Feature Upsamplers: Bridging the Semantic-Spatial Gap**

To achieve true high-frequency spatial resolution without incurring the devastating quadratic memory penalty of overlapping patches, recent literature has successfully pioneered task-agnostic feature upsampling networks. These frameworks sit atop the frozen ViT backbone and leverage the high-resolution RGB input as a guiding prior to structurally upsample the low-resolution feature maps.

#### **FeatUp and Joint Bilateral Upsampling**

FeatUp is a pre-trained, model-agnostic framework capable of upsampling DINOv2 features by factors of ![][image71] to ![][image72] without inducing semantic drift.10 The core mechanism of the most highly optimized FeatUp variant relies on Joint Bilateral Upsampling (JBU). Unlike standard bilinear interpolation, which blindly blends adjacent pixels, JBU enforces strong spatial priors derived directly from the high-resolution source image.  
The JBU module replaces the traditional, fixed Gaussian range kernel with a lightweight, learnable Multi-Layer Perceptron (MLP).27 This MLP evaluates the structural gradients and color variances of the original ![][image3] RGB input, determining precisely how much neighboring tokens should be blended based on visual boundaries.10 If a remote sensing image contains the sharp linear edge of a building, the JBU network explicitly prevents the semantic features of the building class from bleeding into the adjacent shadow or street class, resulting in an exceptionally pixel-dense segmentation map. The JBU upsampler for DINOv2 requires minimal parameter overhead and is seamlessly integrated prior to the cosine similarity head, acting directly on the logits.28

#### **LoftUp and Cross-Attention Guidance**

An advanced alternative to the JBU methodology is LoftUp, a coordinate-based feature upsampler explicitly designed for Vision Foundation Models (VFMs).29 LoftUp fundamentally abandons spatial convolutions in favor of a two-block cross-attention transformer paradigm. It incorporates high-resolution image inputs and positional coordinates via convolutional projections, utilizing the low-resolution DINOv2 features as Keys (K) and Values (V) in a cross-attention layer.30 By forcing the high-resolution RGB pixels to "attend" to the most relevant low-resolution semantic tokens, LoftUp achieves extraordinary boundary adherence, frequently outperforming scenarios where the VFM is run natively at ![][image73] image resolution, while saving approximately ![][image74] the computational cost.29

#### **AnyUp Universal Architecture**

Further generalizing this concept is AnyUp, an inference-time, feature-agnostic upsampling architecture. Existing upsamplers like FeatUp or LoftUp require specific training regimes tuned to the exact dimensionality of DINOv2 or CLIP.11 AnyUp resolves this limitation by combining a feature-agnostic projection layer with a highly localized window-attention upsampling block. It is trained via a self-consistency and input-consistency regularization strategy on localized image crops.12 This architecture perfectly preserves the underlying semantic vector space of the ![][image12]\-dimensional DINOv2 tokens while producing pixel-dense representations, making it highly robust to the distinct spectral geometries encountered in remote sensing domains.

For deployment scenarios where the hardware is strictly bound by the ![][image1] GB T4 limit and cannot host even lightweight auxiliary upsampling MLPs during the backpropagation phase, the implementation of a fully connected Conditional Random Field (DenseCRF) serves as the ultimate fail-safe.

## **The Algorithmic Pipeline for Zero-Shot Semantic Boundary Refinement**

Deploying SAM to refine the boundary geometries of an existing semantic segmentation map represents a paradigm shift from traditional instance segmentation. The objective is not to discover objects, but to mathematically project the coarse semantic logits from the DINOv2 model onto the precise topological boundaries generated by SAM. The standard algorithmic approach documented in the literature is known as pseudo-label refinement via majority voting, a technique popularized by integration frameworks such as "Semantic Segment Anything" (SSA).21

### **The Mask Generation and Majority Voting Architecture**

This pipeline operates sequentially to merge the spatial acuity of SAM with the semantic intelligence of DINOv2. The algorithm relies heavily on SAM's Automatic Mask Generation (AMG) mode, which systematically probes the entire image to discover all possible geometric structures. The formal procedural steps are detailed below.  
First, the ![][image2] RGB aerial patch is passed through the SAM image encoder to extract the dense, intermediate feature manifold. Simultaneously, the DINOv2+CLIP pipeline evaluates the identical image patch, yielding a coarse ![][image2] prediction map delineating the six target semantic classes.  
Second, the algorithm generates a uniform grid of point prompts across the spatial dimensions of the image. For a comprehensive topological mapping, a ![][image15] grid is standard, yielding 1024 individual coordinate points.12 These points are batched and fed sequentially into the SAM mask decoder alongside the image embeddings. The decoder evaluates each point as a potential foreground object, generating a dense set of overlapping, class-agnostic binary masks representing distinct objects, structural sub-components, and background regions.  
Third, the proliferation of masks generated by the dense point grid requires aggressive filtration. The algorithm applies a Non-Maximum Suppression (NMS) algorithm driven by an Intersection-over-Union (IoU) threshold and SAM's internally predicted stability score.11 This filtration eliminates highly overlapping proposals and discards masks with ambiguous or low-confidence edges, yielding a final set of ![][image16] mutually exclusive or minimally overlapping geometric boundary segments.  
The pivotal step is the Semantic Assignment mechanism. For each highly precise, class-agnostic mask ![][image17] generated by SAM, the algorithm interrogates the corresponding spatial region in the coarse DINOv2 semantic prediction map, ![][image18]. The refined semantic class ![][image19] designated for mask ![][image17] is determined by calculating the statistical mode (the majority vote) of the coarse semantic pixels enclosed within the SAM mask boundary.21 Mathematically, this is expressed as identifying the class ![][image20] that maximizes the sum of indicator functions within the mask area.  
Finally, a blank ![][image2] output canvas is instantiated. The pixels falling within the coordinates of mask ![][image17] are uniformly overwritten with the newly assigned class label ![][image19]. Any spatial regions that remain uncovered by the filtered SAM masks default back to the original coarse predictions from DINOv2. The resulting output is a hybrid map featuring the categorical intelligence of the DINOv2 model bounded by the crisp, pixel-perfect topological geometry of the Segment Anything Model.

### **Pathological Failure Modes in High-Resolution Aerial Topography**

While the majority-voting pipeline is mathematically sound and functions admirably on ground-level terrestrial photography, applying it to 20 cm GSD nadir aerial imagery exposes critical, domain-specific failure modes. Aerial topography presents unique challenges related to scale variance, spectral homogeneity, and perspective that directly antagonize SAM's learned priors.  
The most prominent failure mode is pathological over-segmentation. Because SAM operates in a zero-shot capacity without hierarchical semantic constraints, it aggressively segments any structure exhibiting high internal contrast.27 In a 20 cm GSD image, a large industrial warehouse roof is not a uniform plane; it features HVAC units, skylights, structural seams, and variable weathering. The AMG pipeline will frequently partition a single warehouse roof into dozens of localized sub-masks. If the ![][image3] token artifact from the DINOv2 model happens to bisect the warehouse, the over-segmented SAM masks will independently sample different regions of the coarse map. Consequently, half of the roof's HVAC units may receive a majority vote for "Building," while the other half receive a majority vote for "Pavement." Instead of sharpening the boundary of the warehouse, the algorithm bakes the coarse DINOv2 error permanently into the refined map by rigidly assigning incorrect classes to highly detailed structural sub-components.  
A second critical failure mode arises from shadow and spectral confusion. In nadir aerial imagery, shadows cast by high-elevation features like buildings and mature tree canopies exhibit some of the most profound image gradients present in the sensor data.27 SAM's low-level edge detection mechanisms are highly sensitive to these gradients and will frequently generate pristine, high-confidence mask boundaries along the perimeter of a shadow rather than the true physical edge of the object casting it. When the majority voting mechanism assesses the shadow mask, it samples the blurred edge of the DINOv2 prediction. Depending on the fractional overlap, the algorithm may assign the "Building" class to the shadow draped across an adjacent lawn, resulting in a geometrically crisp but physically hallucinated building footprint.  
Conversely, the algorithm struggles with missed non-salient boundaries. In rural and peri-urban landscapes, the transitions between adjacent agricultural fields, dirt tracks, and bare earth often lack distinct visual contrast, blending smoothly over several pixels. SAM has documented difficulties operating in these "visually non-salient scenarios".29 The AMG pipeline will frequently fail to generate a boundary mask across low-contrast topological transitions. In the absence of a high-fidelity bounding mask to project onto, the refinement pipeline defaults to the original ![][image3] DINOv2 token edges, leaving the spatial inaccuracy entirely unresolved in these zones.  
Mitigating these failure modes within the AMG pipeline necessitates aggressive hyperparameter tuning. The mask stability score threshold (stability\_score\_thresh) must be elevated to reject transient boundaries, and the algorithm must explicitly enforce a min\_mask\_region\_area parameter calibrated to the 20 cm GSD to suppress the over-segmentation of rooftop and vehicle sub-components.11 However, tuning alone cannot fully resolve the underlying domain discrepancies.

## **Sequential Execution Dynamics and PCI-Express Latency Penalties**

The parameters of the request propose a practical alternative to concurrent execution: operating DINOv2 and SAM sequentially rather than simultaneously. This protocol entails loading the DINOv2 weights into VRAM, executing the forward pass to generate the coarse predictions, transferring the DINOv2 weights back to the host CPU RAM, loading the SAM weights into the GPU, and subsequently executing the boundary refinement process.

### **VRAM Validation for Concurrent Execution**

The foundational premise underlying the necessity of sequential execution must first be evaluated. The NVIDIA T4 provides 16 GB of VRAM. The concurrent footprint of the DINOv2 \+ CLIP architecture consumes between 6 GB and 8 GB. The previous VRAM arithmetic (Section 2\) definitively established that executing the SAM-ViT-B image encoder on a ![][image2] input using FP16 precision requires approximately 1.5 GB to 1.8 GB of VRAM. Therefore, the combined maximum VRAM utilization of both models operating concurrently is well under 10 GB.  
From a strict memory management standpoint, sequential execution is functionally unnecessary. The T4 GPU can comfortably host both foundational models in VRAM simultaneously, entirely avoiding the severe architectural overhead of state dictionary swapping. However, if unstated secondary processes—such as exceptionally large data loader pre-fetching queues or ancillary system processes—mandate sequential offloading, the mechanical latency must be quantified.

### **Latency Overhead of State Dictionary Swapping**

Transferring massive neural network weight matrices between the host CPU RAM and the GPU VRAM relies exclusively on the server's Peripheral Component Interconnect Express (PCIe) bus interface. The NVIDIA T4 operates on a PCIe Gen3 x16 interface. The theoretical maximum bandwidth of a PCIe Gen3 x16 connection is 15.75 GB/s.  
To execute a swap cycle, the pipeline must first invoke model.to('cpu') on the 8 GB DINOv2+CLIP models, followed immediately by torch.cuda.empty\_cache() to force the PyTorch caching allocator to release the freed memory blocks to the operating system.53 Under optimal hardware conditions, moving 8 GB of data across a 15.75 GB/s bus requires approximately 500 to 700 milliseconds.  
Subsequently, the pipeline must load the SAM-ViT-B weights into the GPU via the model.to('cuda') invocation. Because the SAM-ViT-B weights are comparatively minuscule—occupying only 375 MB in FP32 or 188 MB in FP16—this transfer executes in less than 50 milliseconds.2 However, preparing for the next sequential image patch requires re-loading the 8 GB DINOv2 model, incurring another 500 to 700 millisecond penalty.  
Aggregating these operations reveals that the hardware-level latency penalty for sequential swapping is roughly **1.2 to 1.5 seconds per complete cycle**. If the inference algorithm is structured naively to process a single ![][image2] patch end-to-step before advancing to the next patch, introducing 1.5 seconds of pure memory-bus latency per patch will devastate the throughput of the pipeline. In professional geospatial contexts, an aerial mosaic often comprises tens of thousands of individual ![][image2] patches. An additional 1.5 seconds per patch translates to hours of cumulative dead time where the GPU Tensor Cores sit entirely idle awaiting memory transfers.  
If system constraints absolutely require unloading the models, batch processing is structurally mandatory to amortize the latency. The DINOv2 model must be loaded once and execute its forward pass across thousands of cached patches, serializing the coarse prediction logits to high-speed NVMe storage or system RAM. Only after the primary semantic pass is complete across a massive batch should the GPU memory context swap to SAM for the bulk refinement pass. Under no circumstances should the models be swapped out on a per-patch basis.

# **Mitigating Spectral and Semantic Domain Shifts in Open-Vocabulary Remote Sensing Segmentation**

## **Introduction to Vision-Language Alignment in Remote Sensing**

The transition from fully supervised, closed-set semantic segmentation to Open-Vocabulary Semantic Segmentation (OVSS) represents one of the most profound architectural shifts in contemporary Earth Observation (EO) and remote sensing image analysis. Foundational Vision-Language Models (VLMs), particularly Contrastive Language-Image Pre-training (CLIP), have catalyzed this shift by learning a joint multimodal embedding space where the cosine similarity between corresponding image and text representations is maximized. This theoretical framework theoretically enables zero-shot inference, allowing models to segment arbitrary classes based purely on textual descriptions without requiring exhaustive, pixel-level annotations in the target domain.1 However, the deployment of these zero-shot capabilities to high-resolution aerial and satellite imagery introduces profound and often catastrophic challenges driven by severe domain shifts. The foundational pre-training of architectures such as the CLIP ViT-B/32 relies predominantly on internet-scraped natural images. These datasets are overwhelmingly characterized by human-centric perspectives, horizontal camera angles, distinct object-background dichotomies, and standard lighting conditions. Conversely, aerial imagery introduces nadir (top-down) orthographic projections, high-density object packing, scale variations, and unique spectral distributions that systematically disrupt the visual priors learned by standard VLMs.3  
A particularly acute manifestation of this modality gap occurs when models encounter color-based or spectral domain shifts across different geographical regions. This is distinctly evident when attempting to transfer a segmentation model trained or anchored on the ISPRS Potsdam dataset to the Darmstadt DOP20 dataset. The ISPRS Potsdam dataset, captured at a highly granular 5cm Ground Sample Distance (GSD), features a specific architectural topology where the "Building" class is visually dominated by gray, dark, and flat concrete rooftops.1 When such a system is deployed in a zero-shot capacity on the Darmstadt DOP20 dataset, which is captured at a 20cm GSD and where buildings predominantly feature red terracotta pitched tile roofs, the model frequently suffers a complete failure in class assignment. Specifically, the red-tiled Darmstadt buildings are routinely misclassified as "Clutter"—which corresponds to class 5 in the standard ISPRS taxonomy. This misclassification is not a random stochastic artifact; rather, it is a fundamental, predictable consequence of how the CLIP joint embedding space resolves semantic ambiguity, how the "Clutter" class is both textually and visually defined in historical datasets, and how the geometry of the text embedding space manages out-of-distribution (OOD) spectral signatures.2  
To fully resolve this failure mode, it is necessary to conduct an exhaustive investigation into the mathematical mechanics of the CLIP ViT-B/32 embedding space under conditions of spectral domain shift. This report addresses the expected cosine similarity dynamics between generic and highly specified textual prompts, evaluates advanced prompt engineering mechanisms—including explicit enumeration, material anchoring, negative prompting, and prototype averaging—and examines unsupervised target domain adaptation techniques such as Test-Time Adaptation (TTA) and Source-Free Domain Adaptation (SFDA). Furthermore, it synthesizes the current literature on color-based domain shifts in remote sensing and concludes with a mathematically and empirically grounded operational architecture for prompt design. The ultimate objective is to provide a systemic methodology to maximize the cosine similarity isolation of the Building class while strictly minimizing overlap with the Clutter class.

## **The Semantic Ontology of Remote Sensing Datasets and the Pathology of "Clutter"**

To comprehend why a red terracotta pitched roof is mathematically closer to "Clutter" than to a generic "Building" in the CLIP embedding space, one must first deconstruct the semantic ontology of the training data. The ISPRS semantic labeling datasets, notably Potsdam and Vaihingen, rely on a strict six-class taxonomy: Impervious Surface, Building, Low Vegetation, Tree, Car, and Clutter/Background.5 While the first five classes possess relatively tight semantic and geometric definitions, the sixth class—Clutter—acts as a pathological catch-all category.  
In the official dataset definitions, the Clutter class encompasses everything that does not fit into the primary urban categories. Consequently, the ground truth annotations for Clutter include water bodies, tennis courts, bare soil, construction sites, shipping containers, and miscellaneous urban debris.8 Visually, bare soil, construction dirt, and tennis courts in European aerial imagery often possess rich red, brown, and terracotta spectral signatures. During any implicit feature learning, prior alignment, or dataset-specific prompt tuning, the visual concept of "Clutter" becomes heavily and inextricably entangled with the color red and its associated granular textures.  
When the frozen CLIP vision encoder—particularly a ViT-B/32 architecture operating on 32x32 pixel patches—processes a Darmstadt red terracotta roof at a 20cm GSD, a single patch corresponds to a 6.4m by 6.4m area on the ground. At this resolution, the dominant low-level features extracted by the self-attention mechanisms are the red hue and the textured, grid-like pattern of the tiles. In the CLIP joint embedding space, these specific visual feature vectors exhibit a higher cosine similarity to the latent representation of "bare red earth" or "red tennis court" than they do to the latent representation of a "flat gray concrete slab." Because the text prompt "clutter or miscellaneous urban surface" is semantically broad enough to accept these diverse background features, the similarity maximization equation inherent to CLIP selects Clutter as the winner over a generic "building rooftop".7  
This ontology reveals that the misclassification is driven by a combination of spectral overlap and semantic underspecification. The Building prompt fails to claim the "red/terracotta" visual space, while the Clutter prompt natively absorbs it due to historical biases in the remote sensing taxonomy.

### **Dimensional Anisotropy and the Modality Gap**

A critical, well-documented pathology of the CLIP text embedding space is its dimensional anisotropy—often referred to in the literature as the "narrow cone" phenomenon or representation collapse.13 Despite having hundreds of dimensions (512 for ViT-B/32), the embeddings for all text prompts tend to cluster in a highly constrained, narrow region of the hypersphere. Consequently, the baseline cosine similarity between almost any two distinct text prompts is overwhelmingly positive and artificially high. The text-to-text similarity distribution is structurally skewed because the contrastive pre-training objective pushes paired images and texts together, but it does not explicitly enforce orthogonality between distinct, unpaired text concepts.17  
This anisotropy dictates that lexical overlap dominates the text-to-text similarity metric. When two prompts share syntactical structures or key prefacing tokens (e.g., "aerial view of a..."), their text embeddings will be geometrically adjacent. The self-attention mechanism in the text Transformer acts as an attention sink for these early, repeated tokens, meaning the final representation is heavily weighted by the shared context regardless of the divergent semantic payloads at the end of the sentence.13

## **Advanced Mechanisms for Target Domain Prompt Engineering**

Addressing the systemic misclassification of red-tiled buildings requires transitioning from naive text querying to mathematically principled prompt engineering. The generic prompt "aerial view of a building rooftop" fails because the visual feature vector extracted from the Darmstadt imagery is pushed outside the high-confidence decision boundary of the generic building prototype and falls into the basin of attraction for the clutter prototype. The following mechanisms evaluate how to reshape the Building prototype to capture the red roof features reliably.

### **Explicit Visual Enumeration and Prompt Ensembling**

Explicit visual enumeration involves replacing a generic class noun with a disjunctive list of exhaustive visual manifestations. Instead of mapping the class "Building" to a single generalized semantic point, enumeration forces the text encoder to span a broader subspace covering all expected domain variants.  
By explicitly listing visual variants—such as "flat gray roof," "red pitched tile roof," and "dark asphalt roof"—the theoretical objective is to inject precise visual attributes that match the target domain.22 However, simply concatenating these into a single, highly verbose string (e.g., "aerial view of a building with a flat gray roof or a red pitched tile roof or a dark asphalt roof") is highly suboptimal and frequently counterproductive. The CLIP text Transformer struggles with lengthy, contradictory attribute lists within a single forward pass, resulting in an embedding that suffers from representation collapse, essentially averaging out to a generic, uninformative vector that fails to trigger on any specific feature.14  
The mathematically sound approach to explicit enumeration is prompt ensembling. Each visual variant is processed entirely independently through the text encoder to produce a set of distinct embeddings ![][image7]. During inference, the similarity score is calculated against the image for each prompt individually. The system can then take the maximum similarity score across the ensemble (max-pooling) rather than blindly averaging them. This approach allows the system to act as a mixture of experts, where the "red pitched tile roof" prompt activates strongly on the Darmstadt data without being mathematically suppressed by the "flat gray roof" prompt.11

### **Material and Texture Anchoring in Remote Sensing**

Remote sensing imagery fundamentally lacks the structural geometric cues present in natural terrestrial images (e.g., building facades, windows, doors, human scale context) because of the nadir perspective. Consequently, the CLIP vision encoder relies disproportionately on low-level texture, frequency, and color features to resolve objects in aerial views.1  
Anchoring prompts to materials rather than structural objects capitalizes on this inherent bias. When a prompt relies heavily on the word "building," the CLIP vision encoder searches for structural geometry—edges, right angles, and shadows. However, when a prompt is anchored via terms like "terracotta," "clay tile," or "red ceramic," CLIP's attention heads shift to search for spectral and textural signatures. Because the Darmstadt dataset's primary defining feature for buildings is the red terracotta texture, material anchoring aligns perfectly with the feature extraction hierarchy of the vision encoder.1  
Furthermore, specific material terms are less semantically entangled with background classes. While "clutter" might visually resemble a generic "red roof" due to a shared color space with bare earth, the specific textural token "terracotta" carries highly specific, artificial, and geometric connotations (e.g., repeating, uniform tile patterns) that are distinctly different from natural earth or chaotic debris. This specific linguistic cue pulls the text embedding safely away from the clutter boundary, allowing the model to differentiate between red dirt (clutter) and structured red ceramic (building).10

### **The Linguistic Refinement Ceiling and Low-Data Regimes**

While Test-Time Adaptation provides a sophisticated mathematical workaround, it is crucial to recognize the inherent limits of prompting in remote sensing. A landmark study on vision-language adaptation for satellite imagery—specifically evaluating segmentation models under severe domain shifts—demonstrated that zero-shot prompting frequently hits an impenetrable "linguistic refinement ceiling".27 The researchers tested 60 distinct prompt variants, ranging from simple labels to exhaustive domain terminology, precise appearance descriptors, and contextual cues. The findings revealed that every engineered variant underperformed compared to even a simple label baseline, and no amount of linguistic engineering could fully bridge the gap between CLIP's natural-image representations and satellite-specific spectral distributions.  
The study conclusively demonstrated that under severe spectral domain shifts, prompting is inherently bounded by the pre-trained weights of the vision encoder. However, the study also revealed a powerful alternative: providing as little as 0.1% labeled target data (roughly 8 to 10 annotated images) for lightweight supervised adaptation (e.g., Low-Rank Adaptation, LoRA, or full fine-tuning) overwhelmingly surpassed the absolute best possible zero-shot prompt engineering or TTA methods.27  
This phenomenon is critical for operational design. Labeling just 5 to 10% of the available target data recovers roughly 85% of the maximum achievable intersection-over-union (mIoU). Therefore, while TTA and advanced prompt engineering are powerful tools for strict zero-shot constraints, if the Darmstadt project allows for even a minuscule labeling budget (e.g., manually annotating just 5 images containing red roofs), a supervised few-shot alignment using parameter-efficient fine-tuning will mathematically guarantee vastly superior domain adaptation and boundary delineation compared to relying solely on soft prompt optimization.

## **Empirical Literature on Color-Based Spectral Domain Shifts**

The failure mode observed when transitioning from gray flat concrete roofs (Potsdam) to red terracotta pitched roofs (Darmstadt) is a classic manifestation of a spectral domain shift. The broader remote sensing and computer vision literature has extensively documented the catastrophic failure of natural-image-trained VLMs when subjected to geographic, seasonal, atmospheric, and sensor-based spectral shifts.4

### **Documented Failures and Solutions**

Published works addressing color-based domain shifts in CLIP-based aerial segmentation frequently point to environmental and illumination variances as the primary culprits. For example, research on the "Multi-Weather DomainShifter" framework demonstrated that semantic segmentation performance degrades drastically when target domains undergo sudden color transformations. When a domain shifts from clear conditions (green vegetation, gray roads) to snowy conditions (white coverage) or dusty conditions (red/brown tinting), the visual embedding of the target class changes its coordinates entirely, rapidly crossing the rigid decision boundaries of background classes.52 In these scenarios, classes like "Low Vegetation" and "Tree" suffer massive accuracy drops because their visual appearance is fundamentally altered in the color spectrum.  
To mitigate these color-based shifts, the research community has employed several advanced solutions. The first is cross-domain few-shot segmentation (CD-FSS), which seeks to align the shifted target features with the source features using contrastive regularization. By mapping both domains to a domain-agnostic feature space, the model learns to rely on structural features rather than purely spectral ones.45  
A more targeted solution involves dynamic multi-scale aggregation, as implemented in networks like CD2FSAN. This architecture introduces dynamic feature selection to explicitly correct cross-modal misalignment caused by domain-specific spectral variations. It effectively narrows the modality gap between natural-image-trained CLIP features and domain-specific remote sensing imagery by adjusting to complex spatial and geometric variations that accompany color shifts.3  
Furthermore, the most comprehensive solution has been the development of models specifically continually pre-trained or fine-tuned for remote sensing, such as GeoRSCLIP, RemoteCLIP, and SegEarth-OV.4 These models attempt to solve the domain gap by exposing the vision encoder to millions of diverse aerial images paired with rich textual descriptions during a secondary pre-training phase. This ensures that diverse visual instantiations—such as "red roof" and "gray roof"—are both tightly mapped to the generic "building" text embedding in the latent space. However, if a base, unmodified CLIP ViT-B/32 is utilized without this domain-specific continuous pre-training, the model lacks this specialized manifold. Consequently, the burden falls entirely on the prompt engineer and the inference architecture to manually partition the embedding space to accommodate the spectral shift.
